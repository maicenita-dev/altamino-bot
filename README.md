# altamino-bot

Bot de entretenimiento y horóscopo para AltAmino.

## Estructura

src/
  horoscope.js   -> comando de horóscopo
  games.js       -> minijuegos (dado, 8ball, ship, etc.)
  tts.js         -> texto a audio
  commands.js    -> registro de comandos

## Instalación

npm install

## Comandos

- /horoscopo <signo>
- /roll, /dice <n>, /flip, /8ball, /percent, /ship, /choose, /rps
- /tts <texto>
